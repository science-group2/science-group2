# Proving Ground

Three interactive simulations showing how Newton's laws of motion explain road safety:
seatbelts and inertia, braking distance and mass, and collision forces.

## Viewing

Open `index.html` in any browser, or visit the published GitHub Pages URL.

## Files

| File | Contents |
| --- | --- |
| `index.html` | Landing page linking to all three simulations |
| `law_1.html` | First law — seatbelts and passenger ejection |
| `law_2.html` | Second law — braking distance of an empty vs loaded car |
| `law_3.html` | Third law — equal and opposite forces in a two-vehicle collision |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |

No build step required. Each page is self-contained and loads Tailwind CSS
and Google Fonts from a CDN, so an internet connection is needed.

## Sources

Safety figures are cited from the U.S. National Highway Traffic Safety
Administration (NHTSA) and the Federal Motor Carrier Safety Administration (FMCSA).
